# Arvo — Caderno de Campo Digital

Aplicativo web da Arvo para gerenciar digitalmente os manejos (plantio e aplicação) registrados em campos demonstrativos agrícolas, substituindo planilhas e aprovações via WhatsApp.

## Como rodar

```bash
npm run dev
```

Depois abra [http://localhost:3000](http://localhost:3000) no navegador.

## Stack

- Next.js (App Router, TypeScript) + Tailwind CSS
- Prisma + SQLite (banco de dados local)
